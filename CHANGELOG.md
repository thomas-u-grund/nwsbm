# Changelog

## [1.0.0] - 2026-11-20
- First stable release: the syntax, the stored results and the options are kept from here on within 1.x.
- `nwsbmplot` new plot types: `type(icl)` (ICL against the number of blocks, the selected number marked; with `icl(exact)` the exact ICL plus the `blockmodels` ICL on a second axis; two-mode: one line per number of blocks of mode 2), `type(expected)` (posterior expected tie values T1 pi T2' by block, eight grey levels), `type(membership)` (stacked bars of the membership probabilities, ordered by block and certainty; two-mode: one panel per mode); aliases `type(data)` = `matrix` and `type(meso)` = `blocks` as in R `sbm`.
- `nwsbmplot` new options: `sort` (actors within a block by decreasing certainty, matrix and expected), `colors()` (block colours: `default`, `gray` or a list of colours), `export()` (graph export by extension). Directed block graphs: arrowheads now end at the rim of the nodes and the two directions of a pair run side by side.
- Dialog `nwsbmplot.dlg` has the new plots and options. New test `cscripts/test_nwsbm_plots.do`.
- Mata library rebuilt (new helpers `sbm_perm`, `sbm_axes`, `SbmPlotExpected`, `SbmPlotMember`; `SbmPlotMatrix` has a `sort` argument): after merging with other branches that change the library, rebuild it with Stata 17.
- `estat icl` stars the cell the fit selected (`e(Q)`, `e(Q2)`). It used to find the largest ICL itself through a rounded macro value, so with exactly tied cells (common with `icl(exact)`, where a fit with empty blocks has the partition of a fit with fewer blocks; e.g. the degree-corrected model on the Southern women with `maxblocks(4 4)`) it could star a different cell (4 x 1) than the fit's own table (1 x 1). The tie rule is now one documented rule: cells within 1e-9 of the largest ICL tie and the first row of the table wins (smaller Q, for two-mode networks the smaller Q1 and then the smaller Q2). Fit results are unchanged.
- Test `cscripts/test_nwsbm_icltie.do` (data `dev/ref/davis_matrix.csv`).

## [0.4.0] - 2026-11-19
- Degree-corrected two-mode model: `degreecorrected` with `model(poisson)` now also fits two-mode networks (the degree-corrected latent block model, R `greed` `DcLbm`); `icl(exact)` gives the exact ICL of `greed` for it (the terms that do not depend on the partition are left out, as in `greed`).
- Standard errors of the covariate coefficients: `e(se_beta)` and `e(V_beta)` (inverse information of the coefficients with the block parameters profiled out, conditional on the estimated memberships); the coefficient table shows standard errors, z, p-values and confidence intervals. The R packages give none.
- Faster Bernoulli covariate model: tabulated logistic terms, one pass over the cells for both sides of a two-mode network and for directed networks, one visit per pair for undirected networks; 2.5 to 3 times faster (n = 100: 5.6 to 2.2 s, n = 200: 18.2 to 6.3 s for `maxblocks(5)`, one thread) with the same ICL to 1e-8 relative.
- `greedy` (with `icl(exact)`): greedy node swaps and merges on the exact ICL, as the hybrid search of `greed`; for the Bernoulli SBM, the degree-corrected Poisson SBM and the degree-corrected two-mode model. The result is never below the plain exact ICL; memberships are hard.
- `blockvar`: Gaussian model with a variance for every pair of blocks (`e(sigma2_block)`; `e(sigma2)` is the pooled residual variance); not in R `blockmodels`.
- `orderblocks`: blocks numbered by decreasing size.
- Dialog `nwsbm.dlg`: block variances, criterion, greedy search, order blocks.
- Checked: standard errors against logit / poisson / regress (one block, 1e-8 relative or better; two-mode too) and against the regression on block-pair dummies at the hard partition (within 1 percent); degree-corrected two-mode against greed 0.6.2 on 3 fixtures (same numbers of blocks, ARI 1, exact ICL to 5e-8 relative); greedy against greed on 8 fixtures; block variances against the planted values and the empirical block statistics; the earlier fixtures against R `sbm` and `greed` unchanged. macOS, Stata 17 and 18; Linux and Windows plugins are built by the workflow.

## [0.3.0] - 2026-11-19
- Dyadic covariates for the Bernoulli, Poisson and Gaussian models, one-mode (undirected, directed) and two-mode: `covariates(netlist)` (networks of the session), `absdiff(varlist)`, `same(varlist)`, `signeddiff(varlist)` (from node variables). Link (logit, log, identity) of the mean = block parameter + coefficients x covariates; coefficients in `e(beta)`, number in `e(ncov)`, names in `e(covariates)`; the coefficients count in the ICL. The plugin holds dense n x n matrices (Poisson and Gaussian: n^2 Q per sweep, closed-form or Newton M step on the coefficients with the block parameters profiled out; Bernoulli: n^2 Q^2 per sweep, joint Newton M step with line search, starts screened at a loose tolerance and the selected fits polished). Not with `degreecorrected` or `icl(exact)`.
- `restarts()` default depends on the size of the network: 10 up to 500 actors, 4 up to 1500, 2 above; at most 4 for the Bernoulli model with covariates. `e(restarts)` holds the number used.
- Dialog `nwsbm.dlg`: covariate fields; restarts is a field (blank = default).
- Checked: agreement with R `sbm` 1.0.0 / `blockmodels` 1.2.1 on 9 fixtures with covariates (same Q, ARI 1, ICL to 5e-8 relative, coefficients to 3e-5; Bernoulli two-mode excepted, see below), one-block fits against `glm`/`lm`, recovery of planted partitions and coefficients, error paths. Deviations from R: R's Bernoulli and Poisson covariate models treat missing ties as zeros (nwsbm leaves them out); R's Bernoulli two-mode covariate model reports a PL above the maximal log likelihood (nwsbm reports the true value); `sbm` uses an approximate Bernoulli covariate estimator by default (`fast = TRUE`), nwsbm matches the exact one.
- Timing of the 0.2.0 single-thread path re-measured next to 0.1.0 on the same machine and load: identical (no slowdown).
- Run so far (macOS only): see the test logs; Linux and Windows not run.

## [0.2.0] - 2026-11-19
- Edge models: `model(poisson)` for counts and `model(gaussian)` for real-valued ties (shared variance estimated, or fixed with `sigma2(#)`), for undirected and directed one-mode networks; objective and ICL as in R `blockmodels`/`sbm` (Poisson includes the log-factorial term, Gaussian one extra parameter for the variance).
- `degreecorrected` (with `model(poisson)`): degree-corrected block model (Karrer and Newman 2011) with the degree parameters profiled out (proportional to the observed degrees).
- Two-mode networks: the latent block model, `blocks(#1 #2)` or `maxblocks(#1 #2)` / `minblocks(#1 #2)` (blocks of mode 1 and mode 2), Bernoulli, Poisson and Gaussian; results `e(Q1)`, `e(Q2)`, `e(alpha2)`, `e(blocksize2)`, `e(pi)` (block of mode 1 by block of mode 2).
- `icl(exact)`: the exact ICL of R `greed` (conjugate priors) for the Bernoulli model and the degree-corrected Poisson model of one-mode networks without missing ties; the table keeps the criterion of `blockmodels` in `e(ICLbm)`.
- `threads(#)`: the starts of one number of blocks are evaluated by independent threads (default one per core); the result does not depend on the number of threads. `fast`: at most two random starts and no merge pass.
- `estat icl` and `estat blocks` after a fit; `nwsbmplot` (blocked adjacency matrix, block graph) with dialog `nwsbmplot.dlg`; `nwsbm.dlg` has the new options.
- Not in this version: covariates (see TODO), multiplex and dynamic networks.
- Run so far (Stata 17 BE on macOS only): agreement with R sbm 1.0.0 for Poisson and Gaussian (6 fixtures, undirected, directed, missing ties) and for two-mode networks (4 fixtures), with greed 0.6.2 for the degree-corrected model and the exact ICL, recovery of planted partitions, error paths, timing. Not run: Stata 18/19, Windows, Linux.

## [0.1.0] - 2026-11-19
- First version: `nwsbm netname, blocks() maxblocks() minblocks() model(bernoulli) seed() restarts() generate() replace` fits the Bernoulli stochastic block model (undirected = blockmodels `SBM_sym`, directed = `SBM`) by variational EM in the native plugin `sbm_vem`; missing ties are masked. ICL as in R `blockmodels`/`sbm` (expected complete-data log likelihood minus the BIC-type penalties, the entropy is not added). Starts: spectral clustering of the residual matrix (subspace iteration, k-means), splits of the (Q-1) solution, merges of the (Q+1) solution, `restarts()` random starts. Results in `e()` (ICL table, connectivity matrix `e(pi)`, block proportions and sizes), memberships and probabilities by `generate()`.
- Dialog box `nwsbm.dlg` (menu entry Statistical Models in the core menu, opens with `db nwsbm`): network, blocks, maxblocks, minblocks, model, restarts, seed, generate and replace.
- Not in this version: Poisson/Gaussian edges, degree correction, latent block model (two-mode), covariates, plots, `estat`.
- Run so far (Stata 17 BE on macOS only): agreement with R sbm 1.0.0 on 8 fixtures (same Q, ARI 1.0, ICL equal to 1e-5 at the selected Q), recovery of planted partitions, error paths, missing plugin, timing against R. Not run: Stata 18/19, Windows, Linux (plugins for Linux and Windows are built by the workflow in `.github/workflows`).
