# Releasing nwsbm

The master release procedure for all packages of the family is `RELEASING.md` of the core repository (nwcommands). This file keeps only what is specific to nwsbm.

- The public repository will be https://github.com/thomas-u-grund/nwsbm (branch `main`); it does not exist yet. The CI commits the plugins only after a push to `main` that touches `native/` or the workflow file; a manual run builds but does not commit. Creating the repository, pushing and tagging are the owner's decision.
- Versions: `VERSION` + `python3 tools/set_version.py` / `python3 tools/set_version.py --check`; semantic versioning.
- Build the Mata library with Stata 17: `StataBE -e do lib/build.do` (the build stops under a newer Stata unless `NW_ALLOW_NEWER_STATA=1`).
- Build the plugin: `cd native && make macos` (macOS), `make unix` (Linux); Windows by `cl /LD /O2 /DSYSTEM=STWIN32 /I spi sbm_vem.c spi\stplugin.c /Fe:..\lib\plugins\windows\sbm_vem_windows.plugin`. Remove a plugin a running Stata has loaded before copying a rebuilt one over it.
- Tests: `NWCORE=<core checkout> cscripts/run_tests.sh`. The reference fixtures are regenerated by `Rscript dev/ref_sbm.R dev/ref` (R packages sbm and blockmodels).
- Integration into the core (`nwinstall`, `nwversion`, website) is a core release and is not part of this repository.
- Not yet verified on Linux or Windows.
