## What this package follows

`nwsbm` fits stochastic block models (Holland, Laskey and Leinhardt 1983; Nowicki and Snijders 2001) by variational EM. The reference implementations are the R packages `blockmodels` (Leger) and `sbm` (Chiquet, Donnet and Barbillon), both GPL, whose objective function and ICL it follows; the degree-corrected model and the exact ICL planned for later versions follow `greed` (Come et al.). The code of nwsbm is written independently from the published methods; no code of these packages is included.
